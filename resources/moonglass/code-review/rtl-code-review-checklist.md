# RTL 代码审查清单（QA 阶段逐条裁决）

每条裁决为 `pass` / `waived`（需具名豁免 waiverId）/ `not_applicable`（需注明理由），
结果写入 `rtlqa/code-review-verdicts.json`。本清单只覆盖 lint 工具查不出的语义项，
静态规则项（LATCH/MULTIDRIVEN/clk-rst-in-comb 等）由 lint 门禁兜底，不重复裁决。

| ID | 检查项 | 审查要点 |
|---|---|---|
| CR-01 | 复位策略一致 | 全设计同步/异步复位选择一致；异步复位释放经同步器；复位有效期间输出满足规格默认值 |
| CR-02 | 跨时钟域 | 所有 CDC 路径有同步器/握手/FIFO；无裸组合逻辑跨越；与 CDC 扫描结果互相印证 |
| CR-03 | 状态机 | 状态编码完备；有 default/非法态恢复分支；无死锁状态；初始态明确 |
| CR-04 | 握手与背压 | AXI/ready-valid 在背压下数据不丢、不重、不死锁；气泡处理符合协议 |
| CR-05 | 寄存器语义 | 地址映射、位域、读写副作用（读清零/W1C 等）与接口规格逐条一致 |
| CR-06 | 计数器与指针 | 溢出、回绕、空/满边界行为已定义；饱和策略符合规格 |
| CR-07 | 错误路径 | 非法输入、异常序列、超时/中止的行为已定义且与失效安全目标一致 |
| CR-08 | 位宽与符号 | 截断/扩展处意图明确；无隐式符号位错误；跨位宽赋值有显式说明 |
| CR-09 | 可综合残留 | 无延时语句、initial 初始化语义、X 赋值等仿真专有结构残留在可综合 RTL |
| CR-10 | 调试可观测性 | 关键内部状态可观测（观测点/断言配合验证）；故障可注入、可定位 |
| CR-11 | 复位后初始状态 | 寄存器初始值与输出默认值满足规格书"上电行为"条款 |
| CR-12 | 规格开放点 | 无 TBD/待澄清条款流入综合；遗留决策已在 docs/06_validation/ 记录 |
